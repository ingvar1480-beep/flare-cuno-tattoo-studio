# FLARE CUNO TATTOO STUDIO

Сайт тату-салона с каталогом работ, фильтрами по стилям и календарём записи.

## Локальный запуск

```bash
npm start
```

Открыть `http://localhost:3000`.

## Календарь

Расписание редактируется в `availability.json`:

```json
{
  "weekly": { "0": "off", "1": "free", "2": "free", "3": "busy", "4": "free", "5": "busy", "6": "free" },
  "2026-12-24": "busy"
}
```

`0` — воскресенье, `6` — суббота. Статусы: `free`, `busy`, `off`.

## Публикация на GitHub и Vercel

1. Создать новый репозиторий на GitHub.
2. Загрузить содержимое этой папки в репозиторий.
3. В Vercel выбрать **Add New → Project**, импортировать репозиторий и нажать **Deploy**.
4. При необходимости добавить переменную `BOOKING_WEBHOOK_URL` в настройках Vercel. Вебхук может отправлять заявки в Telegram через Make/n8n или в CRM.

Заявки отправляются в `/api/bookings`. На Vercel они логируются, если вебхук не настроен.

## Фотографии

Когда будет готов путь к фотографиям, заменить изображения в `assets/works/` и обновить `src`/`data-full` в `index.html`.
